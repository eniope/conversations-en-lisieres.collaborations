# Journal d'effectuation

Ce journal ne raconte pas ce que l'enquête trouve. Il documente comment elle se fabrique. Chaque page publiée ailleurs sur ce site est une version, datée, d'un dispositif en construction. Entre deux versions, il y a un épisode : une situation, une épreuve, une question apparue, une bifurcation, un futur essayé.

Distinguer les deux tient toute la méthode. La version est l'état visible à un moment donné. L'épisode est ce qui a fait passer d'une version à la suivante. C'est ce passage, d'habitude invisible, que le journal rend observable.
