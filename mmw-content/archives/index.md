# Archives

Les versions passées du dispositif, gardées telles quelles. Une version archivée n'est pas un brouillon corrigé : c'est un état qui a réellement été public à un moment, et qu'on peut encore consulter pour voir d'où vient la version courante. Ce qui fait passer d'une version à la suivante se lit dans le [journal d'effectuation](/journal/).
